# Task 4: Common Network Security Threats

## Overview

This project presents a research report on common network security threats, their attack methods, real-world impact, and mitigation strategies.

## Threats Covered

- Denial-of-Service (DoS) and Distributed Denial-of-Service (DDoS)
- Man-in-the-Middle (MitM)
- IP Spoofing
- DNS Poisoning and Spoofing

## Project File

- `network_security_threats_report.md` — The complete research report.

## Purpose

To understand common network attacks and identify practical security measures that network administrators can implement to reduce risk.
